# Готовые релизы

[English version](README.md)

В этой директории намеренно хранятся готовые сборки DBA Trainer непосредственно в Git.

Для каждой опубликованной версии используется отдельная директория:

```text
releases/
└── v0.2.0/
    ├── dba-trainer-android-v0.2.0.apk
    ├── dba-trainer-tui-linux-x86_64-v0.2.0.tar.gz
    └── dba-trainer-tui-windows-x86_64-v0.2.0.zip
```

Бинарные файлы являются результатами сборки, а не исходной точкой проекта. Перед добавлением сюда они должны быть пересобраны из соответствующего Git tag и проверены.

Release APK для Android необходимо всегда подписывать одним и тем же постоянным project keystore, чтобы будущая версия могла обновить уже установленное приложение. Keystore и пароли нельзя коммитить в репозиторий.
