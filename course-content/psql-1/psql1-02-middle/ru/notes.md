# Middle — уверенный psql

## 2. Механизм

На этом уровне psql становится инструментом для скриптов, диагностики и ежедневной автоматизации.

### \copy и COPY

`\copy` выполняет SQL `COPY`, но чтение/запись файла происходит **на стороне клиента psql** и с правами пользователя операционной системы, запустившего psql.

```text
\copy users TO 'users.csv' CSV HEADER
\copy users FROM 'users.csv' CSV HEADER
```

Серверный `COPY table TO '/path'` работает с файловой системой сервера PostgreSQL и требует соответствующих серверных прав.

### Форматирование вывода

Полезные команды:

```text
\x              expanded output
\timing         время выполнения запросов
\pset ...       параметры форматирования
\a              aligned/unaligned
\t              tuples only
```

`\x` особенно удобен для широких строк: результат выводится вертикально.

### Ввод и вывод

```text
\i file.sql     выполнить файл
\o file.txt     перенаправить результаты в файл
\o              вернуть вывод на экран
```

### Переменные psql

Установка:

```text
\set foo 42
```

Обычная подстановка:

```sql
SELECT :foo;
```

Для SQL-литерала и идентификатора есть безопасные формы:

```sql
SELECT :'value';
SELECT * FROM :"table_name";
```

Это важно: обычная `:name` — текстовая подстановка, а специальные формы корректно экранируют SQL-литерал или идентификатор.

### \g, \gx и query buffer

`psql` хранит текущий текст запроса в query buffer.

- `\g` отправляет текущий запрос серверу;
- `\gx` выполняет запрос с expanded output;
- `\p` показывает буфер;
- `\r` очищает буфер;
- `\e` открывает буфер во внешнем редакторе.

`\g filename` может направить результат в файл, а `\g |command` — в программу.

### \gset

`\gset` выполняет запрос, который должен вернуть не более одной строки, и записывает столбцы результата в переменные psql.

```sql
SELECT current_database() AS db, current_user AS usr \gset
\echo :db :usr
```

Можно указать префикс переменных.

### \watch

`\watch` повторяет текущий запрос через заданный интервал. Это удобно для наблюдения за статистикой или состоянием процесса.

```text
SELECT now(), count(*) FROM pg_stat_activity;
\watch 2
```

### Условные блоки

Скрипты psql поддерживают:

```text
\if ...
\elif ...
\else
\endif
```

Это условная логика самого клиента, не PL/pgSQL и не SQL `CASE`.

### Шаблоны \d*

Большинство объектных команд (`\dt`, `\di`, `\df`, `\dn` и др.) принимают шаблон. Вариант с `+` обычно добавляет подробности: размеры, права, комментарии или другие свойства — в зависимости от типа объекта.

## 3. Важные детали и покрытие тестов

Ниже собраны детали, которые проверяются вопросами этой темы. Они сгруппированы по разделам исходной документации, чтобы их можно было связывать с механизмом, а не запоминать как отдельный список ответов.

### Метакоманды

- **\copy.** Передаёт данные через клиент psql и использует доступ к локальной файловой системе клиента. `\copy` выполняет COPY, но файл/программа обслуживается клиентом psql.
- **\timing.** Включает или выключает показ времени выполнения SQL-команд. `\timing` показывает время выполнения каждого SQL-оператора.
- **\x.** Переключает расширенный режим вывода. `\x` эквивалентен `\pset expanded`.
- **\i / \include.** Читает и выполняет команды из файла как введённые с клавиатуры. `\i` / `\include` включает файл команд.
- **\o / \out.** Перенаправляет результаты запросов в файл. `\o` / `\out` задаёт направление обычного вывода результатов.
- **\gset.** Выполняет запрос и сохраняет столбцы единственной строки результата в переменные psql. `\gset` требует ровно одну строку и создаёт переменные по именам столбцов.
- **\watch.** Повторно выполнять текущий/последний запрос с заданным интервалом. `\watch` циклически выполняет запрос, пока не будет остановлен или не достигнут count.
- **\copy и локальная файловая система.** Файлы читаются/пишутся psql-клиентом. Документация подчёркивает клиентскую природу `\copy` и передачу данных между клиентом и сервером.
- **\p, \r, \g, \w.** \p выводит буфер. Несколько метакоманд psql управляют ещё не отправленным SQL в query buffer.
- **\g.** Отправляет текущий query buffer серверу; без аргументов по сути подобна завершающей точке с запятой; может одноразово направить результат в файл или pipe. `\g` выполняет буфер и может временно задать параметры вывода или направление результата.
- **\gx.** Она работает как \g. `\gx` — вариант `\g` с expanded=on для этого выполнения.
- **\if / \elif / \else / \endif.** \if. psql поддерживает вложенные условные блоки из этих метакоманд.
- **\d+.** Похожа на \d. Модификатор `+` у `\d` расширяет отображаемую информацию.

### Переменные

- **\set.** Метакомандой \set. `\set имя значение` создаёт/изменяет переменную psql.
- **:имя.** :foo. Двоеточие перед именем вызывает подстановку переменной.
- **\set / \unset.** Это пары имя/значение. Раздел «Переменные» описывает установку, просмотр и удаление значений.

### Параметры

- **-A, --csv, -x, -t.** -A включает unaligned output. Документация связывает параметры командной строки с соответствующими режимами/метакомандами.

### Шаблоны поиска

- ***, ?, *.* и кавычки.** `*` соответствует любому количеству символов. Раздел «Шаблоны поиска» описывает wildcard и правила кавычек.
