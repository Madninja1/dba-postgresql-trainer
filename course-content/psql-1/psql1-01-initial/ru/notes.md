# Initial — основы psql

## 2. Механизм

`psql` — интерактивный терминальный клиент PostgreSQL. Он отправляет SQL серверу, показывает результаты и имеет собственные **метакоманды**, начинающиеся с обратной косой черты.

### Подключение

Основные параметры командной строки:

```text
-d DBNAME   база данных
-h HOST     сервер
-p PORT     порт
-U USER     пользователь
```

Пример:

```bash
psql -h localhost -p 5432 -U app -d appdb
```

Те же значения могут задаваться переменными окружения `PGDATABASE`, `PGHOST`, `PGPORT`, `PGUSER`.

Для пароля можно использовать `.pgpass`, чтобы не вводить его вручную при каждом подключении.

### SQL и завершение команды

Обычный SQL в интерактивном режиме обычно отправляется серверу после точки с запятой:

```sql
SELECT
    current_database(),
    current_user;
```

Перенос строки сам по себе запрос не завершает.

### Метакоманды

Метакоманды обрабатывает сам `psql`, а не сервер PostgreSQL.

Часто используемые:

```text
\conninfo     информация о текущем соединении
\c DB         переподключиться
\l            список баз данных
\dt           список таблиц
\d NAME       описание объекта
\q            выход
\?            справка по метакомандами
\h SELECT     SQL-справка по команде
```

`\d` для отношения показывает столбцы и их типы, а также связанные индексы, ограничения, правила и триггеры. `\d+` показывает больше подробностей.

### Запуск команды и файла

Одну команду можно передать через `-c`:

```bash
psql -d appdb -c 'SELECT now();'
```

Файл выполняется через `-f`:

```bash
psql -d appdb -f script.sql
```

В интерактивном psql файл можно подключить метакомандой:

```text
\i script.sql
```

`-c` и `-f` можно использовать несколько раз и комбинировать.

Важно: одна строка `-c`, содержащая несколько SQL-команд, отправляется серверу как один запрос и при отсутствии явного управления транзакциями выполняется как одна транзакция.

### Справка psql

```bash
psql --help
psql --help=options
psql --help=commands
psql --help=variables
```

Внутри psql:

```text
\?          справка по метакомандами
\h          список SQL-команд
\h CREATE TABLE
```

### Шаблоны объектов

Метакоманды семейства `\d` умеют выбирать объекты по шаблону. Например, `\dt public.*` ограничит список таблицами схемы `public`.

## 3. Важные детали и покрытие тестов

Ниже собраны детали, которые проверяются вопросами этой темы. Они сгруппированы по разделам исходной документации, чтобы их можно было связывать с механизмом, а не запоминать как отдельный список ответов.

### Описание

- **Назначение psql.** Терминальный клиент PostgreSQL. psql позволяет интерактивно выполнять запросы, читать их из файлов и использовать метакоманды.

### Подключение к базе данных

- **-d / -h / -p / -U.** `-d` / `--dbname` задаёт базу данных или строку подключения.
- **Параметры подключения.** -d — база данных. Для подключения используются -d, -h, -p и -U.
- **PGDATABASE/PGHOST/PGPORT/PGUSER.** PGDATABASE. Документация psql прямо перечисляет эти переменные среды подключения.

### Параметры

- **-U / --username.** `-U` / `--username` задаёт имя пользователя для подключения.
- **-f / --file.** psql читает команды из файла. `-f` читает файл и даёт дополнительные возможности вроде номеров строк в сообщениях об ошибках.
- **-c / --command.** Передаёт psql команду для выполнения. `-c` принимает серверную командную строку или одиночную backslash-команду; для смешивания используют несколько -c или ввод.
- **--help=тема.** Документация перечисляет темы options, commands и variables.

### Метакоманды

- **\conninfo.** `\conninfo` выводит сведения о текущем соединении.
- **\c / \connect.** \c или \connect. `\connect` меняет соединение и принимает базу, пользователя, host, port или conninfo.
- **\l / \list.** \l или \list. `\l` / `\list` выводит список доступных баз данных.
- **\dt.** Группа `\dE/\di/\dm/\ds/\dt/\dv` фильтрует отношения по типу; `t` означает table.
- **\q / \quit.** \q или \quit. `\q` завершает интерактивный терминал.
- **Общий формат метакоманд.** Начинаются с обратной косой черты. Документация определяет некавыченный ввод с `\` как метакоманды psql.
- **\d[S+].** Столбцы и типы; NOT NULL и значения по умолчанию; связанные индексы и ограничения. `\d` описывает отношение и связанные свойства/объекты.
- **\l, \dn, \du, \dt.** \l — базы данных. Документация содержит специализированные `\d*` команды и `\list`.
- **\? [тема].** Показывает справку psql. `\? [тема]` предоставляет справочную информацию по psql.

### Ввод SQL-команд

- **Точка с запятой.** Когда встречается завершающая точка с запятой. Конец строки сам по себе обычно не завершает SQL-команду в psql.
