# Шаг 2. Базовый язык Rust

## 1. Тема

Rust — **статически типизированный** язык: тип каждого значения должен быть известен во время компиляции. Компилятор часто выводит тип автоматически, но при неоднозначности требуется явная аннотация.

Базовый слой языка включает:

```text
переменные и константы
        ↓
типы данных
        ↓
выражения и функции
        ↓
ветвление
        ↓
циклы
```

Ключевые слова Rust зарезервированы языком и не могут использоваться как обычные имена переменных и функций.

---

# 2. Механизм

Основная идея базового Rust: **значение всегда имеет конкретный тип, а значительная часть конструкций языка является выражениями и поэтому сама производит значение**.

Например:

```rust
let x = 5;
```

Здесь `5` — выражение, вычисляющее значение, а `let x = 5;` — инструкция, связывающая это значение с именем `x`.

Это различие особенно важно для функций, блоков, `if` и `loop`.

```rust
let x = {
    let a = 3;
    a + 1
};
```

Блок `{ ... }` является выражением. Его последнее выражение `a + 1` вычисляется в `4`, поэтому:

```text
x = 4
```

Ключевой момент:

```rust
a + 1     // выражение → возвращает значение
a + 1;    // инструкция → значение не возвращается
```

Точка с запятой способна изменить смысл кода.

# 3. Важные детали

## Переменные, `mut`, константы и shadowing

Переменные неизменяемы по умолчанию:

```rust
let x = 5;
```

После этого нельзя сделать:

```rust
x = 6; // ошибка
```

Для изменяемой переменной нужен `mut`:

```rust
let mut x = 5;
x = 6;
```

Неизменяемость позволяет компилятору гарантировать, что значение неожиданно не изменится. `mut` явно показывает, что изменение предусмотрено программой.

### Константы

Константа объявляется через `const`:

```rust
const MAX_SIZE: u32 = 100;
```

От обычной неизменяемой переменной она отличается следующим:

```text
let                     const
────────────────────────────────────────
неизменяем по умолчанию всегда неизменяема
тип часто выводится      тип указывается обязательно
значение runtime допустимо только константное выражение
обычная область          можно объявлять и глобально
```

`mut const` невозможен.

Имена констант принято писать:

```text
UPPER_CASE_WITH_UNDERSCORES
```

Константы подходят для значений, которые имеют один смысл во многих частях программы.

---

### Затенение — shadowing

Rust позволяет создать **новую переменную с тем же именем**:

```rust
let x = 5;
let x = x + 1;
```

Второй `x` затеняет первый.

Во вложенной области это работает локально:

```rust
let x = 6;

{
    let x = x * 2; // 12
}

// снова доступен x = 6
```

Главное отличие от `mut`:

```text
mut
→ изменяется значение существующей переменной
→ тип переменной изменить нельзя

shadowing через let
→ создаётся новая переменная
→ тип можно изменить
```

Поэтому допустимо:

```rust
let spaces = "   ";
let spaces = spaces.len();
```

Первый `spaces` — строка, второй — число.

А это недопустимо:

```rust
let mut spaces = "   ";
spaces = spaces.len(); // другой тип
```

**Правило:** `mut` нужен для изменения значения; shadowing — для преобразования значения с сохранением удобного имени.

## Типы данных

Rust должен знать тип всех значений на этапе компиляции.

Часто работает вывод типов:

```rust
let x = 5;
```

Но при неоднозначности тип задаётся явно:

```rust
let guess: u32 = "42".parse().expect("Not a number!");
```

Основные типы в этой главе делятся на:

```text
скалярные
├── integer
├── floating point
├── bool
└── char

составные
├── tuple
└── array
```

### Целые числа

Знаковые:

```text
i8  i16  i32  i64  i128  isize
```

Беззнаковые:

```text
u8  u16  u32  u64  u128  usize
```

`i` — signed integer, `u` — unsigned integer.

`isize` и `usize` зависят от архитектуры: 32 бита на 32-битной системе и 64 бита на 64-битной.

`usize` особенно используется при индексировании коллекций.

Если тип целочисленного литерала не уточнён, по умолчанию используется:

```rust
i32
```

Тип можно указать суффиксом:

```rust
57u8
```

Допустимы разные формы литералов:

```rust
98_222       // decimal
0xff         // hexadecimal
0o77         // octal
0b1111_0000  // binary
b'A'         // byte, u8
```

`_` внутри числа используется только для читаемости:

```rust
1_000 == 1000
```

### Переполнение integer

Если значение выходит за диапазон типа:

```text
debug-сборка
→ проверка переполнения
→ panic

release-сборка
→ оборачивание значения
```

Полагаться на автоматическое оборачивание считается ошибкой.

Для контролируемого поведения числовые типы предоставляют семейства методов:

```text
wrapping_*    → оборачивание
checked_*     → None при переполнении
overflowing_* → значение + признак переполнения
saturating_*  → ограничение min/max значением
```

---

### Числа с плавающей точкой

Есть два типа:

```text
f32
f64
```

По умолчанию:

```rust
f64
```

`f32` — одинарная точность, `f64` — двойная.

Оба типа соответствуют IEEE-754.

---

### Числовые операции

Основные операции:

```rust
+  // сложение
-  // вычитание
*  // умножение
/  // деление
%  // остаток
```

При целочисленном делении дробная часть отбрасывается в направлении нуля:

```rust
-5 / 3 // -1
```

---

### `bool`

Логический тип:

```rust
bool
```

Имеет два значения:

```rust
true
false
```

Размер — один байт.

Особенно важен для условий.

---

### `char`

```rust
let c = 'z';
let c: char = 'ℤ';
```

`char`:

```text
размер = 4 байта
представляет скалярное значение Unicode
```

Поэтому он не ограничен ASCII.

Важно различать:

```rust
'a'   // char
"a"   // строковый литерал
```

То, что человек воспринимает как один визуальный символ, не всегда соответствует одному `char`; подробнее это разбирается вместе со строками.

---

## Кортежи и массивы

### Tuple

Кортеж объединяет несколько значений, причём их типы могут различаться:

```rust
let t: (i32, f64, u8) = (500, 6.4, 1);
```

Размер кортежа фиксирован.

Получить значение можно индексом:

```rust
t.0
t.1
t.2
```

Или деструктуризацией:

```rust
let (x, y, z) = t;
```

Специальный пустой кортеж:

```rust
()
```

называется **unit type**.

Он представляет отсутствие другого возвращаемого значения. Если выражение ничего другого не возвращает, результатом является `()`.

---

### Array

Массив:

```rust
let a = [1, 2, 3, 4, 5];
```

В отличие от tuple:

```text
tuple → типы элементов могут отличаться
array → все элементы одного типа
```

Размер массива фиксирован.

Тип массива:

```rust
let a: [i32; 5];
```

означает:

```text
тип элемента = i32
длина = 5
```

Повтор одного значения:

```rust
let a = [3; 5];
```

эквивалентен:

```rust
[3, 3, 3, 3, 3]
```

Доступ:

```rust
a[0]
a[1]
```

Индексация начинается с `0`.

Если во время выполнения индекс выходит за границы массива, Rust завершает программу с panic вместо доступа к неправильной области памяти.

```text
индекс < длина → доступ
индекс >= длина → panic
```

Массив подходит, когда число элементов заранее известно и не должно изменяться. Для изменяемого размера книга далее вводит `Vec<T>`.

## Функции и выражения

Функция определяется через `fn`.

Имена функций и переменных принято писать в `snake_case`.

```rust
fn calculate_value() {
}
```

Функция может находиться до или после места вызова в исходном файле, если доступна из соответствующей области видимости.

### Параметры

Тип каждого параметра функции указывается обязательно:

```rust
fn print_value(x: i32) {
}
```

Несколько параметров:

```rust
fn measurement(value: i32, unit: char) {
}
```

Сигнатура функции явно сообщает компилятору ожидаемые типы.

---

### Инструкция и выражение

Это одно из важнейших правил базового Rust.

**Инструкция** выполняет действие и не возвращает значение:

```rust
let x = 5;
```

**Выражение** вычисляется в значение:

```rust
5 + 5
```

Выражениями также являются:

```text
вызов функции
вызов макроса
блок { ... }
if
loop
```

Пример:

```rust
let y = {
    let x = 3;
    x + 1
};
```

`y == 4`.

Последняя строка блока:

```rust
x + 1
```

не заканчивается `;`, поэтому её значение становится значением всего блока.

---

### Возвращаемое значение функции

Тип результата указывается после `->`:

```rust
fn plus_one(x: i32) -> i32 {
    x + 1
}
```

Последнее выражение функции возвращается неявно.

То есть:

```rust
x + 1
```

а не:

```rust
x + 1;
```

Вторая форма возвращает `()`, потому что выражение превращено в инструкцию.

Явный досрочный возврат возможен:

```rust
return value;
```

Но книга отмечает, что обычно функции возвращают последнее выражение.

## Условия и циклы

### `if`

```rust
if condition {
    ...
} else {
    ...
}
```

Условие обязательно должно иметь тип:

```rust
bool
```

Rust не делает автоматической truthy/falsy-конвертации:

```rust
if number { }      // нельзя

if number != 0 { } // можно
```

При цепочке:

```rust
if ...
else if ...
else if ...
else ...
```

выполняется **первая ветка с истинным условием**, остальные уже не проверяются.

---

### `if` как выражение

Так как `if` является выражением:

```rust
let x = if condition { 5 } else { 6 };
```

можно получить значение непосредственно из ветвления.

Но все возможные результирующие ветви должны возвращать совместимый тип:

```rust
let x = if condition {
    5
} else {
    6
};
```

Допустимо.

А:

```rust
let x = if condition {
    5
} else {
    "six"
};
```

не компилируется.

Причина: переменная `x` должна иметь один известный компилятору тип.

---

### `loop`

`loop` выполняет код бесконечно:

```rust
loop {
    ...
}
```

Остановка:

```rust
break;
```

Пропустить остаток текущей итерации:

```rust
continue;
```

Особенность Rust: `loop` может вернуть значение:

```rust
let result = loop {
    if condition {
        break 10;
    }
};
```

Здесь значением `loop` становится `10`.

---

### Метки циклов

При вложенных циклах обычные `break` и `continue` относятся к самому внутреннему циклу.

Можно пометить цикл:

```rust
'outer: loop {
    loop {
        break 'outer;
    }
}
```

Метка начинается с `'`.

Она позволяет указать, какой именно вложенный цикл нужно завершить или продолжить.

---

### `while`

Используется, пока условие истинно:

```rust
while number != 0 {
    number -= 1;
}
```

Механически:

```text
проверить bool
    ↓ true
выполнить тело
    ↓
проверить снова

false
    ↓
выйти
```

Это удобная форма распространённой комбинации `loop + if + break`.

---

### `for`

Для перебора коллекции предпочтительнее использовать:

```rust
for element in array {
    ...
}
```

а не вручную увеличивать индекс через `while`.

Причины, указанные в книге:

```text
короче
безопаснее
меньше риска выйти за границы массива
не нужно вручную синхронизировать индекс и длину
```

Поэтому `for` является наиболее часто используемой конструкцией цикла из рассмотренных.

---

### Диапазоны

Диапазон:

```rust
1..4
```

содержит:

```text
1, 2, 3
```

Верхняя граница не включается:

```text
start..end
→ start ... end - 1
```

Диапазон можно перебирать:

```rust
for number in 1..4 {
}
```

Развернуть порядок:

```rust
for number in (1..4).rev() {
}
```

---

### Комментарии

Обычный комментарий начинается с:

```rust
// комментарий
```

и продолжается до конца строки.

Для нескольких строк:

```rust
// первая строка
// вторая строка
```

Документационные комментарии в книге рассматриваются позже, поэтому здесь их подробно не разбираем.

# 4. Что запомнить

Если сильно сжать всю главу, основа следующая:

```text
1. Rust статически типизирован.
   Тип каждого значения известен при компиляции.

2. let создаёт переменную.
   По умолчанию она immutable.

3. mut разрешает менять значение существующей переменной.

4. Повторный let создаёт новую переменную:
   это shadowing.
   При shadowing можно даже изменить тип.

5. const:
   всегда immutable,
   тип обязателен,
   значение должно быть константным выражением.

6. Основные scalar-типы:
   integer, float, bool, char.

7. Основные compound-типы:
   tuple и array.

8. Tuple:
   фиксированный размер,
   разные типы элементов допустимы.

9. Array:
   фиксированный размер,
   все элементы одного типа,
   выход за границы → panic.

10. Rust различает instructions и expressions.

    expression → вычисляет значение
    statement  → значения не возвращает

11. Точка с запятой может превратить
    возвращаемое выражение в инструкцию.

12. Функция:
    fn name(param: Type) -> ReturnType

    Тип параметров обязателен.
    Последнее выражение обычно является результатом функции.

13. Условие if должно быть bool.
    Не существует автоматического truthy/falsy.

14. if является выражением:
    let x = if condition { 1 } else { 2 };

    Все результирующие ветви должны иметь один тип.

15. Циклы:
    loop  → бесконечный/ручное управление
    while → пока условие true
    for   → перебор коллекции/диапазона

16. break     → выйти
    continue  → следующая итерация

17. loop может возвращать значение:
    break value;

18. Вложенные циклы можно адресовать метками.

19. Для коллекций обычно предпочитай for
    ручному индексированию через while.

20. Диапазон start..end не включает end.
```

Особенно важно вынести из этой главы не перечень типов, а три правила, которые дальше встречаются постоянно:

```rust
// 1. Неизменяемость по умолчанию
let x = 5;

// 2. Блоки и управляющие конструкции могут быть выражениями
let x = if condition { 5 } else { 10 };

// 3. Последнее выражение без ; возвращает значение
fn f() -> i32 {
    5
}
```

На них будет опираться следующий шаг — **владение**, где значения, переменные, области видимости и передача данных между функциями становятся уже центральным механизмом Rust.

**Объём:** примерно **10–12 тыс. символов** с кодом.
**Время переноса в тетрадь:** примерно **50–65 минут**; при сильном сокращении примеров — около **45–55 минут**.
