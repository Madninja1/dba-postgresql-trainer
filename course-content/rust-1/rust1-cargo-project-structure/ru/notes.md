# Шаг 1. Rust + Cargo + устройство проекта

## 1. Тема

Rust — предварительно компилируемый язык: исходный код сначала компилируется в исполняемый файл, после чего этот файл можно запускать отдельно от компилятора Rust. Для одиночного файла можно использовать `rustc`, но реальные проекты обычно ведутся через **Cargo** — систему сборки и менеджер зависимостей Rust. Язык программирования Rust Язык программирования Rust

Основные инструменты:

```text
rustup   — установка и управление версиями Rust
rustc    — компилятор Rust
cargo    — создание, сборка и управление проектами и зависимостями
rustfmt  — форматирование Rust-кода
```

`rustup` также устанавливает локальную документацию; её можно открыть командой:

```bash
rustup doc
```

Обновление Rust:

```bash
rustup update
```

# 2. Механизм

## Компиляция

Минимальная Rust-программа имеет функцию `main`:

```rust
fn main() {
    println!("Hello, world!");
}
```

`main` — точка входа исполняемой программы. `fn` объявляет функцию, а её тело заключается в `{}`. `println!` — **макрос**, а не обычная функция: `!` указывает на вызов макроса. Язык программирования Rust Язык программирования Rust

Одиночный файл можно собрать напрямую:

```bash
rustc main.rs
```

После успешной компиляции получается исполняемый бинарный файл. Компиляция и запуск являются отдельными этапами. Язык программирования Rust

Для реальной разработки вместо прямого вызова `rustc` обычно используется Cargo.

---

## Cargo

Cargo выполняет несколько задач:

- создаёт структуру проекта;
- компилирует код;
- управляет внешними зависимостями;
- загружает и компилирует зависимости;
- повторно использует уже собранные части проекта, если они не изменились. Язык программирования Rust Язык программирования Rust

Создание проекта:

```bash
cargo new my_project
cd my_project
```

Cargo создаёт примерно такую структуру:

```text
my_project/
├── Cargo.toml
└── src/
    └── main.rs
```

Исходный код проекта располагается в `src`. Конфигурация проекта хранится в `Cargo.toml`. Cargo также может инициализировать Git-репозиторий. Язык программирования Rust Язык программирования Rust

---

## Cargo.toml

`Cargo.toml` — основной конфигурационный файл Cargo в формате TOML.

Пример:

```toml
[package]
name = "my_project"
version = "0.1.0"
edition = "2021"

[dependencies]
```

Секция `[package]` содержит параметры самого пакета: имя, версию, редакцию Rust.

Секция `[dependencies]` содержит внешние зависимости проекта. Язык программирования Rust

Например:

```toml
[dependencies]
rand = "0.8.5"
```

При сборке Cargo:

```text
Cargo.toml
    ↓
определение зависимостей
    ↓
загрузка необходимых crates
    ↓
компиляция зависимостей
    ↓
компиляция проекта
```

Зависимости загружаются из реестра; книга указывает **Crates.io** как место публикации открытых Rust-пакетов. Транзитивные зависимости также загружаются автоматически. Язык программирования Rust

## Cargo.lock и воспроизводимая сборка

`Cargo.toml` задаёт **допустимые версии**, а `Cargo.lock` фиксирует конкретные версии, реально выбранные Cargo.

При первой сборке Cargo определяет подходящие версии зависимостей и записывает их в `Cargo.lock`. Следующие сборки используют зафиксированные версии, благодаря чему один и тот же проект можно повторно собрать с тем же набором зависимостей. Язык программирования Rust

Упрощённо:

```text
Cargo.toml
"какие версии разрешены"

        ↓ Cargo выбирает версии

Cargo.lock
"какие конкретно версии используются"
```

`Cargo.lock` не следует редактировать вручную: им управляет Cargo. Язык программирования Rust

Обновить разрешённые зависимости в пределах ограничений `Cargo.toml`:

```bash
cargo update
```

Команда пересчитывает версии и обновляет `Cargo.lock`. Язык программирования Rust

---

## Версии зависимостей

Cargo использует семантическое версионирование.

В приведённом в книге примере:

```toml
rand = "0.8.5"
```

эквивалентно ограничению:

```text
^0.8.5
```

То есть допускаются совместимые версии не ниже `0.8.5`, но ниже `0.9.0`. Переход на несовместимую следующую серию требует изменения требования в `Cargo.toml`. Язык программирования Rust

# 3. Важные детали

## Основные команды Cargo

Для повседневной работы достаточно помнить несколько команд.

### Создать проект

```bash
cargo new project_name
```

### Проверить код

```bash
cargo check
```

Проверяет, компилируется ли проект, но не создаёт исполняемый файл. Поэтому обычно выполняется быстрее полной сборки. Язык программирования Rust

### Собрать

```bash
cargo build
```

Обычная сборка создаётся в:

```text
target/debug/
```

Язык программирования Rust

### Собрать и сразу запустить

```bash
cargo run
```

Если исходники не изменились, Cargo может использовать уже собранный бинарный файл вместо повторной компиляции. Язык программирования Rust

### Release-сборка

```bash
cargo build --release
```

Результат:

```text
target/release/
```

Release-сборка включает оптимизации. Она компилируется дольше, но предназначена для финального быстрого выполнения программы. Измерять производительность книги рекомендует именно на release-сборке. Язык программирования Rust

Итого:

```text
cargo check
    ↓
быстро проверить код

cargo run
    ↓
собрать + запустить

cargo build
    ↓
получить debug-бинарник

cargo build --release
    ↓
получить оптимизированный бинарник
```

## `use` и область видимости

Часть элементов стандартной библиотеки автоматически доступна каждой Rust-программе. Этот набор называется **prelude**.

Если нужного элемента в prelude нет, его можно явно ввести в область видимости:

```rust
use std::io;
```

После этого:

```rust
io::stdin()
```

Без `use` пришлось бы писать полный путь:

```rust
std::io::stdin()
```

Язык программирования Rust Язык программирования Rust

Пока достаточно понимать:

```text
std          стандартная библиотека
std::io      модуль io внутри std
::           переход по пути к элементу
use          ввод пути/элемента в текущую область видимости
```

Систему модулей подробно разберём позже.

## Функция, метод и ассоциированная функция

Уже в начале книги появляются три формы вызова.

### Обычная функция

```rust
some_function()
```

### Ассоциированная функция

```rust
String::new()
```

`new` связана с типом `String`, но вызывается не у конкретного объекта. `::` используется для обращения к связанному с типом элементу.

`String::new()` создаёт новое пустое значение `String`. Язык программирования Rust

### Метод

```rust
object.method()
```

Например:

```rust
io::stdin().read_line(...)
```

Метод вызывается у конкретного значения через `.`. Язык программирования Rust

Сейчас важна только разница синтаксиса:

```text
Type::function()   ассоциированная функция

value.method()     метод значения
```

## Переменные: первое правило

Переменная создаётся через:

```rust
let x = 5;
```

Переменные Rust **неизменяемы по умолчанию**.

Для изменения значения нужна явная изменяемость:

```rust
let mut x = 5;
```

Язык программирования Rust

Это пока только базовое правило; подробно переменные и `mut` относятся к следующему шагу.

---

## Ссылки: только первое знакомство

В книге уже встречается:

```rust
&mut guess
```

`&` обозначает ссылку: код получает доступ к данным без необходимости передавать отдельную копию.

Ссылки, как и переменные, по умолчанию неизменяемы:

```rust
&value
```

Изменяемая ссылка:

```rust
&mut value
```

Подробные правила borrowing здесь запоминать ещё не нужно — это отдельный большой механизм главы о владении. Язык программирования Rust

---

## `Result`: первое знакомство

Некоторые операции могут завершиться неудачно, поэтому Rust возвращает `Result`.

Он имеет два варианта:

```text
Ok    операция успешна
Err   произошла ошибка
```

`Ok` содержит успешное значение, `Err` — информацию об ошибке. Язык программирования Rust

Пример из книги:

```rust
io::stdin()
    .read_line(&mut guess)
    .expect("Failed to read line");
```

`expect`:

```text
Ok(value)  → возвращает value
Err(...)   → завершает программу с указанным сообщением
```

Rust предупреждает, если возвращённый `Result` просто проигнорирован, потому что возможная ошибка осталась необработанной. Язык программирования Rust

Полную обработку ошибок разберём в отдельном шаге.

# Что запомнить

Главная модель первого шага:

```text
Rust-код
   ↓
Cargo
   ↓
rustc + зависимости
   ↓
исполняемый файл
```

И отдельно:

```text
Cargo.toml
    ↓
что требуется проекту

Cargo.lock
    ↓
что конкретно было выбрано

src/
    ↓
исходный код

target/
    ↓
результаты сборки
```

Минимальный рабочий набор команд:

```bash
cargo new project
cargo check
cargo run
cargo build
cargo build --release
cargo update
```

Нужно чётко различать:

```text
rustc                 компилятор
Cargo                 управление проектом и сборкой

cargo check           проверить
cargo run             собрать + запустить
cargo build           debug-сборка
cargo build --release release-сборка

Cargo.toml            требования проекта
Cargo.lock            зафиксированные версии зависимостей

use std::io            ввод элемента в область видимости
String::new()          ассоциированная функция
value.method()         метод
println!               макрос
```

И несколько правил, которые уже начинают показывать стиль Rust:

```rust
let x = 5;       // неизменяемо
let mut x = 5;   // изменяемо

&x               // ссылка
&mut x           // изменяемая ссылка
```

Но **ownership, borrowing, `Result`, модули и типы здесь пока только знакомство**. Полностью их лучше разбирать в соответствующих шагах, чтобы не дублировать материал.
